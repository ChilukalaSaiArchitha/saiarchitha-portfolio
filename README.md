# Chilukala Sai Architha — Portfolio

An immersive, responsive personal portfolio built with React and Vite. The visual direction uses a dark editorial layout, lavender accents, ambient particle motion, and scroll-based section navigation.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Included sections

- Introduction and resume link
- About
- Skills
- Certifications
- Featured projects
- Internship experience
- Education
- Contact

The resume is stored in `public/Architha-Resume.pdf`.
